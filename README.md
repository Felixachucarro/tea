# archivo.tea

Archivo visual e histórico del transporte argentino. Arrancamos por el conurbano bonaerense, de 1983 a hoy.

Cada dato lleva su fuente y su estado: DATO, DATO¹, VERIFICAR, ESTIMACIÓN o SIN DATO. Las imágenes reconstruidas o adaptadas con IA llevan su etiqueta.

## Qué hay acá

- `index.html`: la web (inicio y archivo).
- `libreas/`: **Tu bondi**, la guía de libreas («¿De qué color es tu línea?»).
- `img/`: portadas e imágenes de las fichas.

Es un sitio estático: no necesita instalar nada. Se abre `index.html` en el navegador o se publica con GitHub Pages.

## Créditos

Proyecto sin fines comerciales. Las fotos de terceros se citan en cada ficha con su fuente original.
